# 卡马西平 (Carbamazepine)

## 概况

卡马西平（Carbamazepine）是一种经典的抗惊厥药物，在精神科被广泛作为第一代情绪稳定剂使用。该药物由瑞士Geigy化学公司（现诺华制药前身）的化学家Walter Schindler于1953年合成。其化学结构属于二苯并氮杂䓬类衍生物，在结构上与三环类抗抑郁药（如丙咪嗪）具有高度相似性。卡马西平最初于1962年作为治疗三叉神经痛的药物上市，随后在1965年被批准用于抗癫痫治疗。

在精神医学领域，日本学者Takezaki和Okuma在20世纪70年代率先发现了卡马西平对躁狂症的显著疗效，这一发现极大地拓宽了双相障碍的治疗选择。2004年，美国FDA正式批准卡马西平的缓释剂型（Equetro）用于治疗双相I型障碍的急性躁狂和混合发作。

作为精神药理学史上的重要里程碑，卡马西平的临床应用揭示了两个关键的药理学现象：一是其独特的“自身诱导”（Autoinduction）肝酶代谢特性；二是其引发严重皮肤不良反应（如Stevens-Johnson综合征）与特定基因型（HLA-B*1502等位基因）的高度关联，这成为了精神科药物基因组学临床应用的最成功案例之一。

当前，尽管丙戊酸盐和第二代抗精神病药物在双相障碍的治疗中占据了主导地位，卡马西平因其复杂的药物相互作用和耐受性问题，通常被降级为二线或替代性一线治疗选择。然而，对于特定亚型的双相障碍患者（如快速循环型、混合特征、对锂盐无反应或不能耐受者），以及合并神经病理性疼痛或局灶性癫痫的患者，卡马西平仍具有不可替代的临床价值。

## 药物机制

卡马西平作为情绪稳定剂和抗惊厥药，其确切的作用机制尚未完全阐明，但目前公认的核心机制是**对电压门控钠通道（Voltage-gated Sodium Channels, VGSCs）的阻滞作用**。

1. **电压门控钠通道阻滞**：卡马西平主要结合于处于“失活状态”（inactivated state）的电压门控钠通道的α亚基。在神经元高频放电（如癫痫发作或躁狂发作时的病理性过度兴奋）期间，钠通道频繁打开并进入失活状态。卡马西平通过结合失活状态的通道，延缓其恢复至静息状态的时间。这种“使用依赖性”（use-dependent）的阻滞作用意味着，神经元放电频率越高，卡马西平的抑制作用越强。这有效地阻止了动作电位的高频重复爆发和突触兴奋的扩散，从而在不显著影响正常低频神经传导的情况下，发挥抗躁狂和抗惊厥作用。

2. **调节其他离子通道与神经递质**：
   - **钙通道**：卡马西平也能在一定程度上抑制电压门控钙通道（如L型和N型），减少钙离子内流，进而抑制兴奋性神经递质（如谷氨酸）的突触前释放。
   - **受体结合谱**：卡马西平对经典的精神科受体（如D<sub>2</sub>, 5-HT<sub>2A</sub>, M<sub>1</sub>, H<sub>1</sub>）几乎没有直接的亲和力。然而，它可能通过间接途径增强GABA能神经传导（可能涉及GABA<sub>A</sub>受体相关机制），并对腺苷A<sub>1</sub>受体具有激动作用，这可能与其镇静和抗癫痫效应有关。
   - **细胞内信号传导**：与锂盐类似，卡马西平也能调节细胞内信号级联反应，包括抑制cAMP的生成和肌醇的代谢，这被认为是其长期情绪稳定作用的潜在机制之一。

3. **与疗效及副作用的关联**：
   - **疗效关联**：对钠通道和谷氨酸释放的抑制，直接平抑了双相躁狂患者大脑皮层和边缘系统的过度兴奋，控制躁狂症状及冲动攻击行为。
   - **副作用关联**：广泛的神经元抑制会导致中枢神经系统抑制症状（如头晕、嗜睡、共济失调）。此外，卡马西平能增加肾脏集合管对血管升压素（ADH）的敏感性，导致水钠潴留，这是其引发低钠血症（类似SIADH）的机制。

## 代谢途径和药物相互作用

卡马西平在肝脏中主要通过细胞色素P450系统代谢，其最显著的药理学特征是它既是CYP3A4的底物，又是多种肝酶的**强效诱导剂**。其主要活性代谢产物为**卡马西平-10,11-环氧化物**（Carbamazepine-10,11-epoxide），该代谢物具有与母药相当的抗惊厥和抗躁狂活性，同时也与神经系统毒性密切相关。

### 代谢途径表

| CYP酶/代谢途径 | 作用类型 | 临床意义 |
|----------------|----------|----------|
| **CYP3A4** | 主要代谢酶 / **强诱导剂** | 将卡马西平转化为环氧化物。卡马西平强烈诱导CYP3A4，不仅加速自身代谢（自身诱导），还显著降低其他CYP3A4底物（如多种抗精神病药、口服避孕药）的血药浓度。 |
| **CYP1A2, 2C9, 2C19** | **强诱导剂** | 卡马西平可诱导这些酶，降低经这些途径代谢的药物（如氯氮平、奥氮平、华法林）的浓度。 |
| **UGT (葡萄糖醛酸转移酶)** | **诱导剂** | 诱导UGT酶，显著加速拉莫三嗪、丙戊酸盐等药物的清除。 |
| **环氧化物水解酶** | 代谢环氧化物 | 将活性环氧化物转化为无活性的二醇衍生物。若该酶被抑制（如被丙戊酸盐抑制），会导致毒性环氧化物蓄积。 |

## 不良反应

卡马西平的耐受性个体差异较大，其不良反应涉及中枢神经、血液、皮肤及代谢等多个系统。

### ⚠️ 黑框警告

1. **严重的皮肤反应**：包括Stevens-Johnson综合征 (SJS) 和中毒性表皮坏死松解症 (TEN)。这些反应可能致命。在携带**HLA-B*1502等位基因**的人群（主要为亚洲人群，如汉族、东南亚裔）中风险极高。
2. **再生障碍性贫血和粒细胞缺乏症**：卡马西平可引起严重的骨髓抑制。虽然发生率极低（约2-6/100万），但致死率高。若出现严重的白细胞减少伴感染症状，必须立即停药。

### 常见不良反应 (>10%)
- **头晕、共济失调、嗜睡** (>15%) - 机制：广泛的电压门控钠通道阻滞导致中枢神经系统普遍抑制，以及前庭小脑系统受累。 - 处理建议：缓慢滴定剂量，改用缓释剂型，睡前服用大剂量部分，通常在服药数周后产生耐受。
- **恶心、呕吐** (11%) - 机制：局部胃肠道刺激及中枢催吐化学感受区激活。 - 处理建议：与食物同服，分次给药。
- **视力模糊、复视** (10-15%) - 机制：眼外肌运动神经传导受抑。 - 处理建议：通常是血药浓度达到峰值时的表现（峰值毒性），改用缓释片或降低单次剂量可缓解。

### 偶见不良反应 (1-10%)
- **良性白细胞减少** (约10%) - 机制：轻度的骨髓抑制。 - 处理建议：通常是短暂且可逆的。若白细胞总数 > 3.0×10^9/L 且中性粒细胞绝对值 (ANC) > 1.5×10^9/L，且无感染症状，可继续观察，无需立即停药。
- **低钠血症 / 水中毒** (约5-10%) - 机制：增加肾脏对ADH的敏感性，导致抗利尿激素分泌异常综合征(SIADH)样表现。老年人风险更高。 - 处理建议：定期监测电解质，轻度可限制饮水，重度需停药。
- **肝酶升高** (约5%) - 机制：肝脏酶诱导及轻度肝细胞损伤。 - 处理建议：若转氨酶轻度升高（<正常上限3倍）可观察；若伴有黄疸或显著升高需停药。
- **斑丘疹** (约5%) - 机制：过敏反应。 - 处理建议：任何皮疹出现均应高度警惕SJS/TEN的前兆，建议立即就医评估，必要时停药。

### 罕见但严重不良反应 (<1%)
- **Stevens-Johnson综合征 (SJS) / 中毒性表皮坏死松解症 (TEN)**
- **再生障碍性贫血 / 粒细胞缺乏症**
- **心脏传导阻滞**（房室传导阻滞，多见于老年人或既往有心脏病史者）
- **急性胰腺炎**
- **系统性红斑狼疮样综合征**

## 指南定位

卡马西平在各大精神障碍诊疗指南中主要被定位为双相障碍的**二线治疗**或**替代性一线治疗**，其地位略低于锂盐、丙戊酸盐及第二代抗精神病药物（SGAs），这主要是由于其复杂的药物相互作用和潜在的严重不良反应。

- **中国双相障碍防治指南**：推荐卡马西平作为双相I型障碍急性躁狂发作的一线替代药物或二线药物。对于混合发作、快速循环型患者，当锂盐或丙戊酸盐疗效不佳时，卡马西平具有重要的临床应用价值。
- **CANMAT指南 (加拿大)**：在急性躁狂的治疗中，卡马西平被列为二线推荐（单药或联合治疗）。在双相障碍的维持治疗中，同样作为二线推荐，主要用于预防躁狂发作，对抑郁发作的预防效果较弱。
- **WFSBP指南 (世界生物精神病学联合会)**：将卡马西平列为急性躁狂的证据等级A级药物，但在临床优选顺序上排在锂盐、丙戊酸盐和部分SGAs之后。
- **NICE指南 (英国)**：不推荐卡马西平作为双相障碍的常规一线用药。仅在患者对锂盐、丙戊酸盐或抗精神病药无反应、不能耐受或有禁忌时，才考虑使用卡马西平。
- **特定人群推荐**：在**妊娠期**，卡马西平具有致畸性（增加神经管缺陷、颅面部畸形风险，属FDA妊娠D类），指南强烈建议育龄期女性慎用，若必须使用需补充大剂量叶酸（5mg/d）。在**老年人群**中，因易诱发低钠血症、心脏传导阻滞及药物相互作用，指南建议极低剂量起始并缓慢滴定。

## 理想病人

尽管卡马西平并非所有双相障碍患者的首选，但对于具有以下特征的患者，它可能是非常理想的治疗选择：

| 维度 | 理想特征 |
|------|----------|
| **诊断特征** | 双相I型障碍，以急性躁狂发作或混合发作为主。 |
| **症状特征** | 表现为“烦躁性躁狂”（Dysphoric mania）、严重的易激惹、冲动攻击行为；或属于**快速循环型**（一年内发作≥4次）。 |
| **代谢特征** | 极度关注体重增加或已有严重代谢综合征的患者（卡马西平相对**体重中性**，极少引起肥胖或血脂异常，优于丙戊酸盐和多数SGAs）。 |
| **合并症** | 合并局灶性癫痫、三叉神经痛、舌咽神经痛或糖尿病周围神经病变等神经病理性疼痛的患者（可“一石二鸟”）。 |
| **既往治疗** | 对锂盐治疗无反应（特别是缺乏典型躁狂家族史、非典型症状者），或不能耐受锂盐/丙戊酸盐副作用的患者。 |
| **用药依从性** | 能够严格遵医嘱进行定期抽血化验（血常规、肝功），且不依赖激素类避孕药的患者。 |
