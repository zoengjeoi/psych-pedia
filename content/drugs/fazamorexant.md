# 法赞雷生 (Fazamorexant / YZJ-1139)

## 概况

法赞雷生（Fazamorexant，研发代号：YZJ-1139）是由扬子江药业集团自主研发的化学药品1类创新药，亦是国家“重大新药创制”科技重大专项的重要成果（由江苏海岸药业申报生产）。该药属于新型双食欲素受体拮抗剂（Dual Orexin Receptor Antagonist, DORA），通过高选择性阻断食欲素受体1（OX<sub>1</sub>R）与食欲素受体2（OX<sub>2</sub>R），精准抑制觉醒通路的过度活跃，从而诱导并维持生理性睡眠。

2026年5月19日，中国国家药品监督管理局（NMPA）正式批准法赞雷生上市，使其成为全球首个上市国家为中国的DORA类1类创新药，也是中国境内继莱博雷生（Lemborexant）和达利雷生（Daridorexant）之后获批上市的第3款DORA类失眠治疗药物。目前，该药尚未获得美国食品药品监督管理局（FDA）或欧洲药品管理局（EMA）的批准。

在临床地位上，法赞雷生填补了中国自主研发高选择性DORA类药物的空白。相较于传统作用于GABA<sub>A</sub>受体的镇静催眠药物（如苯二氮䓬类受体激动剂BZRAs及Z-drugs），法赞雷生具有起效快、终末消除半衰期短（约2-4小时）的药代动力学优势。其在大规模临床试验中展现了显著缩短入睡潜伏期、增加总睡眠时间的疗效，且在停药后无反跳性失眠与戒断症状，药物依赖性极低，重塑了失眠障碍以“精准下调觉醒”为核心的现代药物治疗格局。

## 药物机制

法赞雷生的药理作用机制聚焦于中枢觉醒系统的精准调控，属于竞争性双食欲素受体拮抗剂（Dual Orexin Receptor Antagonist, DORA）。

```
中枢觉醒系统 (食欲素神经元)
       │ 释放 Orexin-A / Orexin-B
       ▼
 ┌───────────┐      ┌───────────┐
 │   OX₁R    │      │   OX₂R    │
 └─────┬─────┘      └─────┬─────┘
       │                  │
       └───[ 法赞雷生 ]───┘ (高选择性双重阻断)
              │
              ▼
   特异性下调觉醒驱动信号 (Wake-promoting signals)
              │
              ▼
   促发生理性非快速眼动 (NREM) 与快速眼动 (REM) 睡眠
```

### 1. 受体结合谱与作用靶点
下丘脑外侧区神经元分泌的食欲素-A（Orexin-A）和食欲素-B（Orexin-B）是维持清醒状态的关键神经肽。它们通过与G蛋白偶联受体——食欲素1型受体（OX<sub>1</sub>R）和食欲素2型受体（OX<sub>2</sub>R）结合，兴奋去甲肾上腺素能、组胺能、五羟色胺能及胆碱能觉醒通路。
- **OX<sub>1</sub>R 阻断**：主要抑制由食欲素-A介导的觉醒信号，并调节情绪与应激反应回路。
- **OX<sub>2</sub>R 阻断**：被证实为驱动从清醒向睡眠状态转换的核心靶点，直接抑制清醒维持回路。
- 法赞雷生以纳摩尔级别的亲和力高选择性结合OX<sub>1</sub>R与OX<sub>2</sub>R，阻断两类受体与内源性食欲素的相互作用，不结合GABA<sub>A</sub>、H<sub>1</sub>、5-HT<sub>2A</sub>、D<sub>2</sub>、M<sub>1</sub>或α<sub>1</sub>受体。

### 2. 与临床疗效与安全性的关联
- **生理性睡眠结构的保留**：不同于GABA受体正向变构调节剂（BZRAs）抑制全脑神经活动并破坏慢波睡眠（N3期）与REM睡眠，法赞雷生通过特异性“关闭觉醒阀门”，使患者自然进入并维持符合生理周期的NREM和REM睡眠。
- **起效迅速与低残留效应**：约1小时的快速中位Tmax能够快速阻断入睡期的觉醒冲动，缩短主观与客观入睡潜伏期；2-4小时的较短终末半衰期确保药物在醒来时已基本清除，避免次日清晨的头晕、嗜睡、运动协调障碍或精神运动减退。
- **无躯体依赖与反跳**：该药不激活中脑腹侧被盖区（VTA）的多巴胺奖赏回路，且不引起GABA受体下调或受体脱敏，因此在停药后不诱发戒断综合征或反跳性失眠。

## 不良反应

法赞雷生整体安全性良好，在涵盖1034例患者的Ⅲ期临床试验（NCT05525637 / CTR20212685）中，因不良反应导致的治疗终止率极低（约0.6%），未观察到药物滥用倾向或停药反跳现象。

### ⚠️ 黑框警告 (如有)
*说明：截至NMPA获批说明书，法赞雷生**无黑框警告（Black Box Warning）**。但需注意DORA类药物共有的警示信息：复杂睡眠行为、次日功能损害、睡眠瘫痪和日间过度嗜睡。*

### 常见不良反应 (>10%)
在已完成的注册临床试验中，**未见单项发生率超过10%的药物相关严重不良事件**。整体耐受性良好。

### 偶见不良反应 (1%–10%)
- **头晕（Dizziness）**（发生率≥1%）：机制与前庭系统食欲素通路轻度抑制及夜间血压变异相关。建议服药后立即卧床，避免起立走动。
- **嗜睡 / 宿醉感（Somnolence）**（发生率≥1%）：机制为食欲素受体在晨起时阻断未完全解除（特别是睡眠时间不足7小时或合并中度CYP3A4抑制时）。
- **恶心（Nausea）**（发生率≥1%）：胃肠道局部反应或中枢化学感受区轻度受体影响，多为一过性。
- **高脂血症（Hyperlipidemia）**（发生率≥1%）：机制尚在明确中 [需核实: 代谢通路关联]，试验观察到部分患者血脂生化指标波动。
- **白细胞计数降低（Decreased WBC count）**（发生率≥1%）：多为轻度、暂时性下降，无临床感染并发症关联。
- **谷氨酸氨基转移酶（ALT）升高**（发生率≥1%）：轻度一过性转氨酶升高，停药或继续用药过程中大多可自行恢复。

### 罕见但严重不良反应 (<1%)
- **复杂睡眠行为（Complex Sleep Behaviors）**：包括梦游（Sleepwalking）、睡眠驾驶、在未完全清醒状态下进食或与人交谈，伴有事后遗忘。出现此类事件必须立即停药。
- **睡眠瘫痪（Sleep Paralysis）与入睡/醒前幻觉（Hypnagogic/Hypnopompic Hallucinations）**：在觉醒与睡眠转换期暂时无法活动或言语，机制为REM睡眠要素的非正常侵入。
- **轻度猝倒样症状（Cataplexy-like Symptoms）**：极个别患者可能出现短暂的双下肢肌无力发作，多无诱因，机制与严重下调食欲素信号相关。
- **抑郁症状加重与自杀观念**：精神科药物通用的警示不良反应，需在有自杀倾向或重性抑郁共病患者中严密防范。

## 指南定位

法赞雷生作为中国本土自主研发的首个DORA类1类创新药，其上市代表着中国失眠临床用药进入了“非镇静类觉醒调控”的新阶段。

- **《中国失眠障碍诊断和治疗指南》及中国精神药理学共识**：
  - 传统指南将短-中效BZRAs作为急性或短期药物干预的常用推荐，但受限于耐受性、成瘾性、认知损害及停药反跳，限制连续使用通常不超过4周。
  - 随着法赞雷生（及同类DORA药物）的数据积累，指南与临床路径逐步确立DORA类药物作为失眠障碍（包括入睡困难及睡眠维持困难）的重要一线推荐药物。
  - 特别推荐用于：需要中长期治疗的慢性失眠患者、既往使用GABA受体药物出现耐受或依赖倾向者、老年患者以及对次晨精神运动能力有较高职业要求的个体。
- **国际指南对比（如AASM、ESRS）**：
  - 国际主要睡眠指南（如美国睡眠医学学会AASM、欧洲睡眠研究学会ESRS）已将DORA类药物（如Suvorexant, Lemborexant, Daridorexant）提升为慢性失眠障碍药物治疗的高级别推荐证据。
  - 法赞雷生基于1034例大样本中国人群Ⅲ期临床研究（NCT05525637 / CTR20212685，2025世界睡眠大会首发数据），提供了完全基于中国人群的高等级证据（Level A），确立了其在国内临床实践中的核心地位。

| **诊断特征** | 原发性慢性失眠障碍；共病轻度情绪问题的失眠患者 | 明确诊断为发作性睡病（Narcolepsy）患者（绝对禁忌） |
| **症状特征** | 同时合并入睡潜伏期延长（入睡困难）与中途频繁醒来（维持困难）者 | 仅需特定时段极短时催眠且无法保证7小时睡眠时间者 |
| **代谢特征** | 肝肾功能正常或轻度受损；未同时使用CYP3A4强效抑制剂或诱导剂者 | 重度肝功能损害患者（Child-Pugh C级）；合并服用强CYP3A4抑制剂者 |
| **合并症** | 伴有轻度阻塞性睡眠呼吸暂停（OSA）、慢性阻塞性肺疾病（COPD）的失眠患者（无明显呼吸抑制副反应） | 重度未控制的睡眠呼吸暂停综合征、未控制的重度抑郁症伴自杀倾向 |
| **既往治疗** | 长期使用佐匹克隆、唑吡坦、艾司唑仑等产生心理/躯体依赖，需平稳换药方案者 | 对DORA类药物活性成分或辅料过敏者 |
| **生活方式与依从性** | 每晚有规律的作息安排，能够确保服药后获得**连续7–8小时**充分卧床时间者 | 需夜间频繁紧急值班、驾驶或从事高空作业等需要随时清醒的人群 |

## Counseling (患者教育)

### Q1: 法赞雷生通常在服药后多长时间起效？
**A:** 法赞雷生口服后吸收迅速，在空腹状态下平均约1小时达到血药浓度高峰。因此，您应当在**准备睡觉前的30分钟以内**服药。请注意，服药前应确保您当晚能够保证至少7至8小时的连续睡眠时间；如果在饱餐或进食高脂肪食物后立即服药，起效时间可能会有所推迟。

### Q2: 这个药物需要连续服用多久？可以长期吃吗？
**A:** 法赞雷生的Ⅲ期长期临床试验证明，连续用药6个月仍能保持稳定改善入睡和睡眠维持的疗效，且不产生耐药性。失眠治疗应在专科医师指导下定期评估，当睡眠节律重建后，医师会根据您的恢复情况制定逐渐减量或按需服药的策略。

### Q3: 停药时会出现像安眠药那样的“睡不着反弹”或难受的戒断反应吗？
**A:** 不会。传统的镇静安眠药（如苯二氮䓬类和Z-drugs）通过抑制全脑神经发挥作用，停药容易出现反跳性失眠和躯体戒断。法赞雷生通过精准阻断觉醒信号（食欲素）发挥作用，临床试验明确证实，即使连续用药6个月后停药，也**未观察到反跳性失眠或药物戒断症状**，身体不会对其产生传统安眠药那样的化学依赖。

### Q4: 服药期间有哪些必须警惕的不良反应？
**A:** 
1. **常见轻度反应**：个别患者可能在服药初期出现轻度头晕、嗜睡或恶心，通常随用药适应逐渐减轻。
2. **复杂睡眠行为（需立即停药）**：如果您或家属发现您在服药后、未完全清醒的状态下出现了梦游、夜间无意识做饭/进食、甚至睡眠中驾驶等行为（事后无法回忆），必须**立刻停药并联系医生**。
3. **睡眠瘫痪**：极少数人在刚入睡或刚醒来时可能出现短暂的全身无法动弹（俗称“鬼压床”），通常持续数秒至数分钟，属于药物影响睡眠相转换的现象，不必过度恐慌，但应向医生反馈。

### Q5: 它可以和治疗其他疾病的药物一起吃吗？
**A:** 服药前必须将您正在服用的所有处方药、非处方药及中草药清单告知医生。法赞雷生主要通过肝脏的CYP3A4酶代谢：
- 严禁与强效CYP3A4抑制剂（如抗真菌药酮康唑、抗生素克拉霉素）同服；
- 避免与抗癫痫药（卡马西平、苯妥英钠）或利福平等诱导剂同服；
- 服药当晚**绝对禁止饮酒**，因为酒精会显著加重中枢抑制，导致运动失调和嗜睡风险成倍上升。

### Q6: 饮食方面有什么特殊注意事项吗？
**A:** 
1. **避免高脂大餐**：服药前若进食了油腻、高脂肪大餐，会显著推迟药物达峰时间，可能导致您入睡改善变慢，甚至导致次日清晨药物仍在体内残留而出现晨起困倦。
2. **避免葡萄柚（西柚）及西柚汁**：葡萄柚含有抑制肠道CYP3A4代谢酶的成分，会导致药物血浓度非预期升高，增加副作用风险。

### Q7: 如果半夜醒来发现失眠，可以中途补服一片吗？
**A:** **绝对不可以。** 法赞雷生每晚仅限服用一次，且只能在睡前服用。如果半夜醒来补服，由于剩余卧床时间不足（无法保证后续7小时睡眠），极易导致次日早晨和日间出现严重嗜睡、头晕、步态不稳和注意力无法集中，增加跌倒或交通事故风险。

### Q8: 漏服药物该怎么处理？
**A:** 如果您在临睡前忘记服药，且当时距离您预定的早晨起床时间已不足7小时，请**跳过当晚的剂量**，照常起床，待次日临睡前再按原剂量服用一次即可。切勿在次日早晨或次日晚间服用双倍剂量来“弥补”漏服。
